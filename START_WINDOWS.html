CREATIVECRAFTS FAKTURY • WINDOWS 0.7

Uruchomienie krok po kroku

  1. Rozpakuj całą paczkę ZIP.
    Kliknij ZIP prawym przyciskiem → „Wyodrębnij wszystkie”. Wybierz krótki folder, np. C:\CreativeCrafts albo folder Dokumenty. Nie uruchamiaj programu wewnątrz ZIP-a.
  2. Zainstaluj Python, jeśli go nie masz.
    Pobierz z oficjalnej strony Python. Wybierz standardowy instalator Windows zgodny z Twoim systemem. Program wymaga Python 3.9.2 lub nowszego; kod testowano na Python 3.12. Zaznacz „Add python.exe to PATH”, jeżeli instalator pokazuje tę opcję.
  3. Kliknij dwukrotnie URUCHOM.bat.
    Pierwszy start przygotuje biblioteki PDF, XML i szyfrowania KSeF. Potrzebny jest internet. Przy kolejnych uruchomieniach gotowa biblioteka jest używana bez ponownej instalacji.
  4. Poczekaj na otwarcie przeglądarki.
    Panel działa lokalnie na Twoim komputerze. Pozostaw czarne okno programu otwarte. Jeśli przeglądarka się nie otworzy, skopiuj cały adres wyświetlony w oknie programu. Ctrl+C lub zamknięcie tego okna kończy pracę.

Pierwszy test: PDF bez wystawiania faktury

  1. Otwórz Ustawienia, wpisz dane sprzedawcy i zapisz. Pozostaw wyłączone wystawianie faktur.
  2. Przejdź do Nowa faktura. Formularz ma dane przykładowe.
  3. Kliknij Pobierz podgląd PDF. Podgląd ma oznaczenie „NIE JEST FAKTURĄ”, nie zajmuje numeru i nie trafia do Base.

Drugi test: odczyt zamówień z Base

  1. W Ustawieniach wprowadź token API Base i kliknij „Zapisz klucz Base”. Nie przesyłaj tokenu w rozmowie.
  2. Otwórz Zamówienia z Base, wybierz ostatnie 7 dni i kliknij „Pobierz z Base”. Samo pobranie nie zmienia niczego w Base.
  3. Podgląd dokumentu z Base wymaga istniejącego rekordu faktury. Dokumenty już powiązane z Fakturownią lub KSeF nie są zastępowane. Jeśli wszystkie faktury są już powiązane z Fakturownią, na razie sprawdź listę zamówień i ręczny podgląd PDF.
KSeF w wersji 0.7. Najpierw sprawdź obieg w środowisku testowym. W Ustawieniach wybierz środowisko, zapisz token KSeF, sprawdź połączenie i włącz automat dla nowych B2B. Produkcja oznacza wysyłkę rzeczywistych faktur. Program odbiera status, numer i UPO. Testy API wykonano na symulowanych odpowiedziach; wymagany test integracyjny na Twoim koncie. Szczegóły i ograniczenia znajdziesz w DOKUMENTACJA.md.

Aktualizacja z poprzedniej wersji

Zamknij poprzedni program, rozpakuj nową paczkę do nowego folderu i uruchom URUCHOM.bat. Program korzysta z tej samej bazy w LocalAppData — ustawienia, numery i wystawione faktury pozostają. Najpierw pobierz kopię ZIP ze starego programu. Klucz Base jest odtąd zapamiętywany lokalnie.

Moje faktury — wszystkie dokumenty

Na jednej liście zobaczysz wcześniejsze dokumenty z Fakturowni i nowe wystawiane w programie. Wyszukuj po numerze, nazwie lub NIP; filtruj sprzedaż, koszty, korekty i status płatności. Przyciskami Poprzednia / Następna przejdziesz przez cały zbiór. Szczegóły, oryginalne pliki PDF/JSON i pobrane załączniki pozostają dostępne lokalnie. Brak pobranego PDF jest oznaczony.

Lista kontrahentów

Pobrani kontrahenci i nabywcy wcześniejszych faktur pojawią się automatycznie po aktualizacji. Nowych dodasz przyciskiem + Dodaj kontrahenta lub przy wystawieniu faktury. Użyj do faktury uzupełnia formularz nabywcy; Edytuj zmienia kartotekę bez zmiany starych faktur.

Zakładka importu oraz połączenie API Fakturowni zostały usunięte. Dotychczasowe dane nie wymagają ponownego importu. Kopia ZIP obejmuje całe archiwum oraz nową kartotekę kontrahentów.

Status i sposób zapłaty — wersja 0.3

W „Moje faktury” kliknij Szczegóły / płatność. W archiwum Fakturowni kliknij Szczegóły. Zobaczysz status, zapłaconą kwotę, kwotę pozostałą, termin, sposób i datę zapłaty. Dane wcześniej pobrane z Fakturowni są używane od razu — nie musisz importować ich ponownie, jeśli pola płatności znajdują się w pobranym JSON.

Przycisk Oznacz jako opłaconą uzupełnia pełną kwotę i proponuje dzisiejszą datę. Sprawdź pola i kliknij Zapisz rozliczenie. Wpisuj łączną zapłaconą kwotę. Oryginalny PDF/JSON pozostaje bez zmian; historia lokalna nie jest wysyłana do Base ani Fakturowni.

Nowe faktury mogą zawierać zapłaconą kwotę, datę wpłaty, uwagi i jednostki. W Ustawieniach uzupełnisz nazwę banku, rachunek i dane kontaktowe sprzedawcy. Data wpłaty nie jest zgadywana, jeśli brakuje jej w oryginale.

B2B i XML FA(3) — wersja 0.4

  1. Uzupełnij NIP nabywcy i przygotuj dokument. W „Moje faktury” otwórz szczegóły i kliknij Pobierz XML FA(3).
  2. Najpierw sprawdź import w testowej Aplikacji Podatnika KSeF. Do rzeczywistego wystawienia przygotuj osobny dokument produkcyjny. Ten proces obsługuje przesłanie online w dniu przygotowania; nie obsługuje offline24.
  3. Po przyjęciu dokładnie tego XML wpisz numer KSeF, wybierz środowisko i zaznacz potwierdzenie. Program nie sprawdza przyjęcia przez API. UPO zachowaj osobno.
  4. PDF otrzyma numer KSeF i QR. B2B można przekazać do Base dopiero po potwierdzeniu produkcyjnym. Środowiska test/demo blokują tę wysyłkę.

Korekty

W szczegółach faktury pierwotnej kliknij Wystaw korektę. Podaj przyczynę, numer KSeF pierwotnej faktury lub potwierdź wystawienie poza KSeF. Edytuj stan po korekcie; ilość 0 oznacza zwrot. Sprawdź podgląd PDF i zapisz. Korekta ma osobną numerację; pierwotny PDF pozostaje bez zmian. B2B wymaga własnego przesłania XML do KSeF. Korektę przekazujesz na razie ręcznie — nie podmienia oryginału w Base.

Gdzie są dane?

W %LOCALAPPDATA%\CreativeCraftsFaktury. Folder otworzysz, naciskając Win+R, wklejając tę ścieżkę i zatwierdzając Enterem. Powstaje przy pierwszym uruchomieniu. Nie usuwaj bazy faktury.sqlite3.

Kopia danych jest dostępna w „Moje faktury”. ZIP kopii zawiera dane klientów i nie jest szyfrowany. Klucz Base jest zapamiętywany lokalnie i nie trafia do kopii ZIP.

Jeśli coś nie działa

  • Brak Python: zainstaluj go, zamknij okno błędu i uruchom URUCHOM.bat ponownie.
  • Błąd pobierania biblioteki: sprawdź internet. Przy pierwszym starcie pobierane są zależności z repozytorium pakietów Python.
  • Program przeniesiony do innego folderu: usuń tylko folder .venv w paczce i uruchom ponownie. Baza faktur pozostaje w LocalAppData.
  • Inny błąd: skopiuj treść komunikatu z czarnego okna. Nie kopiuj tokenu API.

Paczka źródłowa z launcherem BAT; nie zawiera instalatora EXE. Logikę sprawdzono w Linuxie, bez uruchomienia na rzeczywistym Windowsie lub koncie Base.
