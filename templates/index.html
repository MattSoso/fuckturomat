Uzupełnij sprzedawcę i otwórz „Nowa faktura”. Przykładowy dokument możesz pobrać bez połączenia z Base i bez nadawania numeru.

Wersja 0.7: krajowe faktury B2C i B2B w PLN, korekty ilości, ceny i VAT oraz eksport XML FA(3). W Ustawieniach skonfiguruj token KSeF i automat dla nowych B2B. Status, numer i UPO znajdziesz w szczegółach. Zacznij od środowiska testowego i sprawdź dokumenty przed użyciem produkcyjnym.

Korekta otrzyma osobny numer PREFIKS-KOR/0001/ROK. Nie zastępuje pierwotnego pliku w Base. Korekty do Base przekazujesz na razie ręcznie.

Sprzedawca

Numeracja roczna: PREFIKS/0001/ROK. Numer początkowy dotyczy tylko nieuruchomionej jeszcze serii dla danego roku. Po wystawieniu faktury licznik nie może być cofnięty w ustawieniach. Użyj osobnego prefiksu, aby nie kolidować z Fakturownią.

Połączenie z Base

Klucz jest zapisany w osobnym pliku lokalnym na tym komputerze i wczytywany przy starcie. Plik nie jest szyfrowany i nie trafia do kopii ZIP. Pobierz go w ustawieniach API swojego konta Base.

Połączenie z KSeF

Token KSeF z uprawnieniem do wystawiania faktur. Puste pole zachowuje token tylko dla tego samego środowiska. Klucz jest zapisany lokalnie w nieszyfrowanym pliku, poza kopią ZIP. Chroń konto Windows i dysk.

Wysyłka online: dzisiejsza data faktury. Archiwum nie jest wysyłane automatycznie. Po zamknięciu programu kolejka czeka do ponownego uruchomienia; zmiana daty blokuje niewysłane dokumenty. Wyłączenie automatu dotyczy nowych faktur; już zakolejkowane dokumenty zachowują zlecenie wysyłki. Testowe dokumenty nie mogą być przekazane do Base.
