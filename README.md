# Fuckturomat — CreativeCrafts Faktury

Program do fakturowania uruchamiany lokalnie na Windows. Wersja 0.7.

## Uruchomienie

1. Pobierz repozytorium (Code → Download ZIP) i rozpakuj całość.
2. Zainstaluj Python 3.9.2 lub nowszy.
3. Uruchom `URUCHOM.bat` — launcher przygotuje środowisko i uruchomi aplikację.

Pełna instrukcja i ograniczenia: [DOKUMENTACJA.md](DOKUMENTACJA.md). Instrukcja graficzna: `START_WINDOWS.html`.

Program obsługuje lokalne faktury, kontrahentów, rozliczenia, PDF/XML FA(3), integrację z Base i wysyłkę do KSeF. Połączenia z Base i KSeF wymagają internetu. Przed użyciem produkcyjnym zapoznaj się z dokumentacją.

Dane i tokeny są przechowywane poza kodem programu. Nie dodawaj do repozytorium baz danych, kopii zapasowych, faktur ani plików z kluczami.
